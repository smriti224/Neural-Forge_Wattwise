# ⚡ WattWise – Intelligent Classroom Energy Optimization System

## 🧠 Overview
WattWise is a context-aware system that optimizes energy usage in classrooms by making real-time, data-driven decisions. Instead of just monitoring devices, it actively analyzes occupancy, timetable, and device states to recommend optimal energy usage.

## 🚀 Why this project?
Classrooms often waste energy due to devices running without need (e.g., AC in empty rooms). Existing systems lack intelligence and context-awareness. WattWise solves this by introducing a decision-making system that aligns energy consumption with actual demand.

## 🔧 Key Features
- **Context-Aware Recommendations** – Suggests actions like turning off AC or lights based on real-time conditions  
- **Timetable Integration** – Uses class schedules to detect expected vs actual usage  
- **Multi-Room Monitoring** – Analyze and switch between different classrooms  
- **Efficiency Scoring** – Quantifies how efficiently energy is being used  
- **Waste Detection** – Flags critical, warning, and informational inefficiencies  
- **Simulation Layer** – Enables testing without real IoT hardware  

## 🏗️ Tech Stack
- **Frontend:** React.js  
- **Backend:** Node.js, Express.js  
- **Architecture:** REST API + Rule-based Decision Engine
