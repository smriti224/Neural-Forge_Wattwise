# ⚡ WattWise — Smart Energy Optimization System

## 📌 Overview
WattWise is a smart energy optimization platform designed to monitor classroom energy usage and provide real-time insights to reduce energy waste.

---

## 🚀 Features

- Real-time classroom monitoring  
- Context-aware analysis  
- Energy waste detection  
- Efficiency scoring  
- Recommendation engine  
- Timetable integration  
- Energy savings estimation  
- Analytics dashboard  

---

## 🛠️ Tech Stack

**Frontend**
- React
- Tailwind CSS
- Recharts

**Backend**
- Node.js
- Express.js
